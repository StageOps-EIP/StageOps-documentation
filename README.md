# StageOps Documentation

Dépôt central de documentation fonctionnelle, technique et académique du projet StageOps.

Ce repository constitue la source officielle de référence pour :
- le cadrage du projet
- la documentation technique
- le suivi des blocs RNCP
- les livrables académiques
- l’architecture système

## Objectifs

- Centraliser la documentation du projet
- Assurer la traçabilité des décisions techniques
- Documenter l’architecture logicielle
- Fournir un support pour l’évaluation académique

## GitHub Wiki

Le Wiki du repository est utilisé pour le suivi des blocs RNCP.

Pages recommandées :

- Modèle de données
- Roadmap produit

## Correspondance RNCP

Chaque bloc RNCP est associé à :
- des issues GitHub
- des modules logiciels
- des livrables documentés

## Livrables principaux

- Cahier des charges
- Architecture technique
- Diagrammes système
- Présentation projet
- Dossier technique

## Bonnes pratiques

- Toute décision technique majeure doit être documentée
- Les diagrammes doivent être versionnés
- La documentation doit refléter l’état réel du code
